# Error E1045: Fluidics Pressure Instability

## Diagnostic Description
During startup prime or sample aspiration cycles, the manifold pressure measured by [[Pressure-Sensor-PS23]] oscillated by more than ±10% or dropped below the mandatory threshold of `114.0 kPa`.

## Common Symptoms Reported by Operators
- "Analyzer stops during startup initialization."
- "E1045 appears intermittently during batch testing."
- "Reagent dispensing volume error on sample carousel."
- "Fluid drops visible on the baseplate below the pump bay."

## Diagnostic Decision Tree
1. **Safety Depressurization**: Initiate wash mode and verify zero line pressure.
2. **Measurement Test**: Connect digital manometer `948-CAL-01` to test port TP-FL-01.
   - Run 3-minute continuous purge.
   - If physical manometer reads `114–126 kPa` but software reports `< 114 kPa`:
     - **Cause**: Transducer drift in [[Pressure-Sensor-PS23]].
     - **Action**: Replace sensor using [[PROC-PUMP-CALIBRATION]].
   - If physical manometer also reads `< 114 kPa`:
     - **Cause**: Plunger seal bypass or hydraulic tubing delamination in [[Pump-P102]].
     - **Action**: Replace pump plunger seal kit `SP-948-230-01`.
